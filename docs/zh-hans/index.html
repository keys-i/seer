@keys-i/seer · 构建时 i18n + SEO

SEO 与本地化：将 50 个手动步骤缩减为一次构建。

先编写各语言的 JSON。Seer 随后逐一校验其结构，并生成静态站点或服务端渲染站点所需的内容和搜索引擎文件。浏览器端无需加载任何 Seer 运行时代码。

“50 个步骤”只是简化表述，按 5 种语言各重复 10 项检查计算；你的实际检查清单会有所不同。

只需两条命令即可开始

安装 Seer，再在站点构建前运行一次。

npm install --save-dev @keys-i/seer
npx seer build

一次构建，取代整张检查清单

  1. 编写各语言 JSON

    共享数据只保留一份，每种语言的译文各放在一个文件中。

  2. 部署前完成校验

    如果存在缺失键、不安全路径、格式错误的元数据或各语言之间结构不一致，Seer 会让构建失败。

  3. 发布易于搜索引擎发现的页面

    读取各语言 JSON，并输出规范 URL、hreflang、JSON-LD、robots.txt 和 sitemap.xml。

继续使用你选择的框架

在构建或启动时只加载一次项目，再将与框架无关的元数据映射到框架原生的 head API。

import { headData, readProject } from "@keys-i/seer";

const project = await readProject();
const metadata = headData(project, "zh-Hans", "home");

能力边界，如实说明

Seer 不会翻译文案或凭空生成 schema，不承诺搜索排名，也不会添加浏览器端本地化运行时。
