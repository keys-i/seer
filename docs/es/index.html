@keys-i/seer · i18n y SEO en tiempo de compilación

SEO y localización: de 50 pasos manuales a una sola compilación.

Escribe el JSON de cada idioma. Seer valida la estructura de cada archivo y genera el contenido y los archivos de búsqueda que necesita tu sitio estático o renderizado en servidor. No se envía ningún runtime de Seer al navegador.

La referencia a «50 pasos» representa diez comprobaciones repetidas en cinco idiomas; tu lista variará.

Empieza con dos comandos

Instala Seer y ejecútalo antes de compilar tu sitio.

npm install --save-dev @keys-i/seer
npx seer build

Una compilación sustituye la lista de tareas

  1. Escribe el JSON localizado

    Guarda los datos compartidos una vez y el texto traducido en un archivo por idioma.

  2. Valida antes del despliegue

    Seer falla si faltan claves, hay rutas inseguras, metadatos incorrectos o estructuras inconsistentes entre idiomas.

  3. Publica páginas fáciles de descubrir

    Usa el JSON localizado y genera URL canónicas, hreflang, JSON-LD, robots.txt y sitemap.xml.

Usa tu framework, no el nuestro

Carga el proyecto una vez al compilar o arrancar y pasa los metadatos independientes del framework a la API de cabecera nativa de tu framework.

import { headData, readProject } from "@keys-i/seer";

const project = await readProject();
const metadata = headData(project, "es", "home");
